# KEBE Alpine Ski Touring & Expeditions

Official web platform for **KEBE Alpine Ski Touring & High-Altitude Expeditions**.

## Features
- **Flagship Departure**: Gappa, Nagar Valley 2027 (Karakoram, Gilgit-Baltistan) — 14-day ski touring expedition.
- **12 Global Destinations**: Zermatt (Switzerland), Gran Paradiso (Italy), Lyngen Alps (Norway), Tian Shan (Kyrgyzstan & Kazakhstan), Kazbek (Georgia), Himalayas (Nepal), Broad Peak & Gappa (Pakistan), Mount Cook (New Zealand), Hokkaido (Japan), Muztagh Ata 7,546m (China), and Patagonia.
- **Interactive Dossiers & Modals**: Technical peak breakdowns, avalanche safety protocols, and IFMGA guidelines.
- **Expedition Cost Estimator**: Real-time cost calculator with EUR / USD currency toggling and 50% deposit breakdown.
- **Athlete Technical Screening**: Pre-qualification application with instant WhatsApp and email dispatch.
- **Full 5-Language Localization**: English, Français, Deutsch, Español, and فارسی (with native RTL layout).
- **Official Booking Terms**: Comprehensive deposits, wire transfer instructions, and cancellation policies.

## Deploying on GitHub Pages
1. Go to repository **Settings** -> **Pages**.
2. Under **Build and deployment**:
   - Source: **Deploy from a branch**
   - Branch: `main` / `root`
3. Click **Save**. The website will be live at `https://<username>.github.io/<repo-name>/`.
